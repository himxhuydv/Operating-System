# Deadlock
It's a state where set of processes waits for the resources that are currently held by other process each process can't let go of their resources beacuse of the system rule.as a result,processes get permanetly stuck or blocked forever as a result of circular waiting resources.each process can't get fully exectued because  of this.
**So,basically the deadlock occcur when there is a circular waiting of the resource that's where the deadlock occur**
## System model
so the number of finite resource is distributed amongs the competing processes.
**Here are fundamental model of process**
**A process proper utilzation happens here.**
**Request**:So,basically a process request the resource first if the resource is avaiable then, it will given to the process is the resource is currently occupied by the second process it has to wait.
**Use**:So,after using it will generally use the resource.and will continue to execute the process
**Release**:So,after process is generally executed it will realesed the resource to use by the another process.
